# Reference Materials

This directory contains reference documentation and materials for CardLyze.

- `Notebook/Card_Data.ipynb`: Contains initial data analysis, column addition, and exploratory logic.
- `data_dictionary/Transaction_Data_Dictionary.docx`: Data dictionary specifying schema and column definitions for VISA, PineLabs, and Vegapay cards.

Do not edit files in reference/ or commit real transaction data files.
